# COLD CASE PHY-03 — The world's earthquake agencies disagree in ways that almost make a signal

Family: geophysics  |  Disposition: **POSTABLE_AS_COLD_CASE**  |  claim_authority=NONE
Members: R71_EARTHQUAKE_MAGNITUDE_ORDERING_V1, r73-earthquake-origin-stratification-v1, earthquake-precursor-resolution-v1, earthquake-reviewed-status-resolution-v1, R1_DEPTH, R2_GEOMETRY, R3_MAGNITUDE_METHOD, R4_HYPOCENTER, R5_CALENDAR, r4-handchecked-confirmation-2019-2025-v1

## The case
USGS, GEOFON, and EMSC report the same earthquakes with small systematic disagreements. If those disagreements have structure - by depth, method, region, era - they expose how seismic truth is manufactured. Ten frozen routes chased it, and one association KEPT SURVIVING: a practical timing-agreement pattern held in all four analysis versions of a hand-checked 2019-2025 cohort - and is blocked from promotion by its own honesty rules (rounded timestamps missed the frozen batch rule, one era block reversed direction, one randomization crossed a cutoff).

## How it died
Powered routes missed practical floors (depth stopped at 0.395 s against 0.4; magnitude ordering never reached 0.10 units); sparse routes had 2.6 to 15.6 percent power; the reviewed-status comparator had 3 confirmation rows. The surviving association sits at WATCH pending a source-agency and processing-lineage explanation test.

## What still stands
Bounded within-floor nulls for several disagreement axes, and one four-version-stable timing association explicitly NOT promoted. Ceiling: catalog bookkeeping structure; the boring explanation (shared processing lineage) is untested and favored.

## What would revive it
Later-era events (25+ in both depth groups), provider revision histories, and agency processing-lineage documentation - which pipeline version stamped which event.

## Card fields (G18 contract)
- plain_meaning: Different agencies' earthquake numbers differ a little, mostly without pattern; one timing pattern refuses to die and we are deliberately not believing it until the boring explanation gets its shot.
- what_it_is_not: Not a precursor or prediction claim, because everything measured is agency bookkeeping; and not a promoted finding, because the frozen rules it missed exist precisely to stop patterns like this from being believed early.
- next_decisive_test: The frozen processing-lineage explanation test on the surviving association, with provider revision metadata.
- what_we_need: Seismic-agency processing-version histories and per-event pipeline metadata; contact with catalog operations staff would unlock several routes at once.
